# IDS_Agent
## Technology
- **LLM (ReAct-style)**: Core Germini-2.0-Flash.  
- **Classifiers**: RandomForest, KNN, LogisticRegression, DecisionTree, MLP, SVC.  
- **Vector DB**: ChromaDB (embedding retrieval).
- **Tooling**: Python, scikit-learn, pandas, numpy, json API.  
- **Evaluation datasets**: ACI-IoT’23.
